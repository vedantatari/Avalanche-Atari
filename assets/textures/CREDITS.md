# Asset credits

## Surface textures (CC0)

Downloaded from [Poly Haven](https://polyhaven.com) (CC0 1.0 public domain) and processed
locally: colour maps converted to greyscale detail maps and resized to 512 px; normal maps
resized. Themes and item types tint the detail maps in code.

| File | Source asset | Authors (per Poly Haven) |
|---|---|---|
| `boulder_detail.jpg`, `boulder_normal.jpg` | [Rock Boulder Cracked](https://polyhaven.com/a/rock_boulder_cracked) | Dimitrios Savva (photography), Dario Barresi (processing) |
| `cliff_detail.jpg`, `cliff_normal.jpg` | [Rock Face 03](https://polyhaven.com/a/rock_face_03) | Poly Haven |
| `snow_normal.jpg` | [Snow 02](https://polyhaven.com/a/snow_02) | Poly Haven |

## Everything else

Rocks, cliffs, trees, the cart, the driver, emblems, particles, sounds, and UI icons are
procedural (generated in code) and were written for this project.
